# 없는 숫자 더하기

- 출처: 프로그래머스 · 월간 코드 챌린지 시즌3
- 문제 ID: 86051
- URL: https://school.programmers.co.kr/learn/courses/30/lessons/86051
- 난이도: Lv.1
- 보드 칸: 구현·시뮬레이션 L1

## 요약
0부터 9까지의 숫자 중 배열 `numbers`에 포함되지 않은 숫자들을 모두 찾아 더한 값을 반환한다.

## 제약
- `numbers`는 0~9의 서로 다른 정수로 이루어진 길이 9 이하의 배열

## 목표 복잡도
N ≤ 9로 사실상 상수. O(1)~O(10) 수준이면 충분. 목표 시간: 5분.

# 삼각 달팽이 (68645)

## 접근
방향전환 시뮬레이션. 변의 길이를 n, n-1, ..., 1로 줄여가며 (아래→오른쪽대각선→위)
순서로 채움. `div % 3`으로 현재 방향 판정, 각 변 끝에서 방향 전환.

## 리뷰에서 지적된 것
디버그용 `print`가 매 셀 채울 때마다 `results` 전체를 출력하고 있었음 — O(n) 작업을
O(n²)번 반복해 전체 O(n³)이 되는 성능 문제. n=5라 안 드러났을 뿐 n=1000이면 체감됨.
리뷰 후 제거.

## 복잡도
O(n²), n ≤ 1000 → 최대 50만 셀. 여유 충분.

## 힌트
2/4 (접근 단계까지) — BFS/DFS 아니라 방향전환 구현이라는 것만 확인받고 직접 완성.

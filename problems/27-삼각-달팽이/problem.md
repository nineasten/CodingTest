# 삼각 달팽이 (68645)

- 출처: 프로그래머스 · 코딩테스트 연습
- URL: https://school.programmers.co.kr/learn/courses/30/lessons/68645
- 난이도: Lv.2 | 보드 칸: 2D 격자 L2-하

## 요약
높이가 n인 삼각형을 1부터 시작해 반시계 방향(아래→오른쪽 대각선→위)으로 달팽이
채우기 한 뒤, 삼각형을 위에서부터 한 줄씩 이어붙여 1차원 배열로 반환.

## 제약
- 1 ≤ n ≤ 1,000

## 목표 복잡도
셀 개수 = n(n+1)/2 ≤ 약 500,000 → O(n²) 시뮬레이션이면 충분.

# 소수 찾기(42839) 회고

- 결과: ✅ 통과, 힌트 1/4
- 접근: `permutations(numbers, i)`로 길이 1~len 전부 순회 → `int(''.join(num))`으로
  선행 0 제거 → 전역 set으로 (길이가 달라도 값이 같아지는 경우 포함) 중복 제거 →
  소수 판정
- 정답성: 예제("011"→2) 직접 추적해 일치 확인
- 복잡도 이슈: `is_prime`이 `range(2, x)`로 √x가 아니라 x까지 돌아 O(x) — 7자리
  최악값(5,040개 순열 × 최대 1e7 판정)이면 이론상 시간초과 위험. 통과는 했으나
  테스트 데이터가 약했을 가능성. 다음엔 `range(2, int(x**0.5)+1)` 반사적으로 적용.
- 잡기술: [[lib/cheatsheet.md]] "수학"(sqrt bound 소수판정), "완전탐색"(set
  comprehension으로 길이 다른 순열 중복 제거) 섹션 추가
- 원인 태그: #복잡도역산누락 — 소수 판정을 짤 때 √x bound를 반사적으로 안 걸고
  `range(2, x)`로 짜서, 자릿수가 늘면 시간초과 나는 잠재 버그를 리뷰에서 발견

# 큰 수 만들기

- 출처: 프로그래머스 · 코딩테스트 고득점 Kit · 탐욕법(그리디)
- 문제 ID: 42883
- URL: https://school.programmers.co.kr/learn/courses/30/lessons/42883
- 난이도: Lv2

## 요약
숫자로만 이루어진 문자열 `number`에서 숫자 `k`개를 제거해 남은 숫자들로 만들 수
있는 가장 큰 수를 구한다. (남은 숫자들의 순서는 원래 순서를 유지)

## 제약
- 1 ≤ number 길이 ≤ 1,000,000
- 1 ≤ k < number 길이

## 목표 복잡도
O(n) — 각 숫자가 스택에 최대 한 번 push/pop, n ≤ 1,000,000이라 선형이어야 통과

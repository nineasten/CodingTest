# 피보나치 수

- 출처: 프로그래머스 · 코딩테스트 연습 · DP
- 문제 ID: 12945
- URL: https://school.programmers.co.kr/learn/courses/30/lessons/12945
- 난이도: Lv.2
- 보드 칸: DP L2-하

## 요약
n번째 피보나치 수를 구해 1234567로 나눈 나머지를 return.
(피보나치: F(0)=0, F(1)=1, F(n)=F(n-1)+F(n-2))

## 제약
- 1 ≤ n ≤ 100,000

## 목표 복잡도
n이 10만이라 재귀+캐시 없는 순수 재귀는 지수적으로 터진다 → 상향식(bottom-up) DP로
O(n) 시간, O(n) 또는 O(1)(롤링 변수) 공간.

## 입출력 예시
| n | return |
|---|---|
| 3 | 2 |
| 5 | 5 |

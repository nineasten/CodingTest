# 프로그래머스 · 코딩테스트 연습
## [12906] 같은 숫자는 싫어 (Lv.1)
https://school.programmers.co.kr/learn/courses/30/lessons/12906

**보드 칸**: 스택·큐 L1 | **목표**: 10분 / O(N)

---

## 문제 요약

배열에서 연속으로 나타나는 숫자는 하나만 남기고 제거한다. 순서는 유지.

## 제약 조건

- 배열 arr의 크기: 1 ≤ len(arr) ≤ 1,000,000
- 원소: 0 이상 9 이하의 정수

## 입출력 예시

### 입력
```
[1,1,3,3,0,1,1]
```

### 출력
```
[1,3,0,1]
```

### 입력
```
[4,4,4,3,3]
```

### 출력
```
[4,3]
```

## 풀이 목표

O(N) 시간복잡도로 풀기. 결과를 스택처럼 관리하며 맨 위와 현재 값 비교.

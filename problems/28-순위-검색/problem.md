# 순위 검색 (72412)

- 출처: 프로그래머스 · 2019 카카오 개발자 겨울 인턴십 · 코딩테스트 고득점 Kit(이분탐색)
- URL: https://school.programmers.co.kr/learn/courses/30/lessons/72412
- 난이도: Lv.2 | 보드 칸: 이분탐색 L2-하

## 요약
지원자 정보(`"언어 직군 경력 소울푸드 점수"`)가 주어지고, 각 조건(와일드카드 `-`
포함)과 점수 기준을 만족하는 지원자 수를 쿼리마다 구한다.

## 제약
- info: 1 ≤ length ≤ 50,000
- query: 1 ≤ length ≤ 100,000
- score: 1 ≤ 100,000

## 목표 복잡도
조건 4개 → 와일드카드 조합 2^4=16가지로 미리 그룹핑(dict[bucket] = 점수 리스트) 후
정렬, 쿼리마다 해당 버킷에서 `bisect`로 임계값 이상 개수 세기.
O((N+M) × 16 × log N) — 완전탐색 O(N×M)이면 시간초과.

# 프로그래머스 · 2019 카카오 개발자 겨울 인턴십
## [64061] 크레인 인형뽑기 게임 (Lv.1)
https://school.programmers.co.kr/learn/courses/30/lessons/64061

**보드 칸**: 2D 격자 L1 | **목표**: 15분 / O(n²)

---

## 문제 요약

n×n 격자(board)에 인형이 채워져 있다. moves 배열은 크레인이 선택하는 열(1-indexed) 순서다. 각 이동마다 해당 열의 맨 위 인형을 뽑아 바구니에 담고, 바구니 맨 위 두 개가 같은 모양이면 함께 사라진다(터짐). 터진 인형의 총 개수를 구한다.

## 제약 조건

- board는 n×n 2차원 배열, 5 ≤ n ≤ 30
- board의 원소는 0(빈칸) 또는 1~n²이내 자연수(인형 모양)
- moves의 길이: 1 ≤ len(moves) ≤ n²
- 각 열에 있는 인형의 개수는 n개 이하

## 입출력 예시

### 입력
```
board = [[0,0,0,0,0],[0,0,1,0,3],[0,2,5,0,1],[4,2,4,4,2],[3,5,1,3,1]]
moves = [1,5,3,5,1,2,1,4]
```

### 출력
```
4
```

---

## 풀이 목표

O(n²) 시간복잡도로 풀기. 각 열을 스택처럼 다루고, 바구니도 스택으로 관리.

# 풀이 기록

## 풀이 전략

**2회 순회**로 구현:
1. 첫 루프: 모든 기록을 순회하며 최종 닉네임 수집 (Enter/Change), Enter/Leave 기록만 ops 저장
2. 두 번째 루프: ops의 Enter/Leave에 대해 최신 닉네임으로만 메시지 생성

## 핵심

- Change는 메시지를 만들지 않고 닉네임만 업데이트
- 각 사용자의 **마지막 닉네임**으로 모든 메시지를 통일
- 순서 유지: Enter/Leave 순서대로 메시지 생성

## 복잡도

- 시간: O(N) — 2회 순회 (상수배)
- 공간: O(M) — 사용자 수 (최대 N)

## 결과

통과 (0/4 힌트)

## 교훈

기록의 시점(Enter/Leave/Change)과 최종 상태(닉네임)를 분리해서 처리하면 간단해진다.

## 문제 요약

모든 음식의 스코빌 지수(scoville)가 K 이상이 되도록, 가장 맵지 않은 두 음식을 섞는
작업(새 스코빌 = 가장 안매운 것 + 두 번째 안매운 것*2)을 반복한다. 모든 음식이
K 이상이 되기까지 필요한 최소 섞기 횟수를 구한다. 불가능하면 -1.

## 제약 조건

- scoville 길이: 2 ≤ len(scoville) ≤ 1,000,000
- scoville 원소: 0 ≤ scoville[i] ≤ 1,000,000
- K: 0 ≤ K ≤ 1,000,000,000

## 입출력 예시

### 입력
```
scoville = [1, 2, 3, 9, 10, 12]
K = 7
```

### 출력
```
2
```

---

## 풀이 목표

O(N log N) 시간복잡도로 풀기. 최소 두 값을 반복해서 꺼내야 하므로 최소 힙(min-heap) 사용.

# 네트워크

- 출처: 프로그래머스 · 코딩테스트 고득점 Kit · DFS/BFS
- 문제 ID: 43162
- URL: https://school.programmers.co.kr/learn/courses/30/lessons/43162
- 난이도: Lv.3 | 보드 칸: BFS·DFS L3-초

## 요약
네트워크란 컴퓨터 상호간에 정보를 교환할 수 있는 연결 구조. 컴퓨터 `n`대와 이들의
연결 정보 `computers`(인접행렬)가 주어질 때, 네트워크(연결된 컴퓨터들의 집합)의
개수를 구한다.

## 제약
- 컴퓨터 개수 `n`: 1 ≤ n ≤ 200
- `computers`: n×n 인접행렬(2차원 배열), 대칭이며 `computers[i][i] = 1`

## 목표 복잡도
각 컴퓨터를 순회하며 미방문이면 BFS/DFS로 연결된 컴포넌트 전체를 방문 처리 →
O(n^2) (인접행렬 전체를 훑는 비용). n≤200이면 최대 40,000번 — 여유 충분.

## 목표 시간
20분

# 풀이 기록

## 결과
✅ 통과

## 리뷰 요약
- 정답성: 맞음. n=1, 완전 고립 케이스로 직접 추적해 확인.
- 복잡도: O(n^2), 여유 충분.
- Fancy 리팩토링: `not_visited` 보조 집합을 따로 관리하는 대신 `visited` 하나만
  두고 `for i in range(n)`으로 전체를 훑는 표준형(컴포넌트 세기 골격)으로 단순화
  가능.

## 배운 것
연결 요소 개수 세기는 보조 자료구조(미방문 집합)를 새로 만들기보다, 인덱스 전체를
`for`로 순회하며 `visited` 하나로 충분한지 먼저 검토.

## 원인 태그
없음 — 힌트 0/4. 도중 `next(iter())` 문법 질문 1회, `not_visited != 0` 버그는
관찰 유도 후 스스로 수정 후 통과.

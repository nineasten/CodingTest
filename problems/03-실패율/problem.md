# [42889] 실패율

- 출처: 프로그래머스 · 2019 카카오 채용연계형
- URL: https://school.programmers.co.kr/learn/courses/30/lessons/42889
- 난이도: Lv.1 | 보드 칸: 정렬 L1

## 요약
게임 스테이지별 도전 기록이 주어진다. 각 스테이지의 실패율(도전했지만 클리어하지 못한 비율)을 계산하고, 실패율이 높은 순서대로 스테이지 번호를 정렬해 반환한다.

## 제약
- 스테이지 수 N ≤ 100
- 각 스테이지의 도전자 수는 N 이상 (모두 1번 이상 도전)
- 실패율이 같으면 스테이지 번호 오름차순

## 목표 복잡도
O(N log N) — 정렬

## 입출력 예시
- N=5, stages=[2,4,2,4,2] → [4,2,1,3,5]
  - 스테이지 1: 도전 5명, 실패 0명 → 실패율 0
  - 스테이지 2: 도전 5명, 실패 3명 → 실패율 0.6
  - 스테이지 3: 도전 2명, 실패 1명 → 실패율 0.5
  - 스테이지 4: 도전 2명, 실패 2명 → 실패율 1.0
  - 스테이지 5: 도전 0명(통과한 모두), 실패율 0
  - 결과: 실패율 순 [4(1.0), 2(0.6), 3(0.5), 1(0), 5(0)]

# [64065] 튜플

- 출처: 프로그래머스 · 2019 카카오 겨울 인턴십
- URL: https://school.programmers.co.kr/learn/courses/30/lessons/64065
- 난이도: Lv.2 | 보드 칸: 문자열 파싱 L2

## 문제 요약
튜플을 표현하는 방식 중 하나인 집합 표기(`{}`) 문자열이 주어진다. 원소 개수가
1개인 부분집합부터 전체 집합까지 원소 개수 오름차순으로 나열되어 있으며, 각
부분집합이 등장하는 순서가 원래 튜플의 원소 순서를 나타낸다. 이 문자열로부터
원래 튜플을 배열로 복원한다.

## 제약
- `s`의 길이: 5 이상 1,000,000 이하
- `s`는 숫자와 `{`, `}`, `,` 로만 구성, 숫자는 0으로 시작하지 않음
- 튜플 원소: 1 이상 100,000 이하 자연수
- 반환 배열 길이: 1 이상 500 이하

→ 목표 복잡도: O(L + n log n)  (L = len(s), n = 튜플 원소 개수 ≤ 500)

## 입출력 예시
| 입력 | 출력 |
|---|---|
| `"{{2},{2,1},{2,1,3},{2,1,3,4}}"` | `[2, 1, 3, 4]` |
| `"{{1,2,3},{2,1},{1,2,4,3},{2}}"` | `[2, 1, 3, 4]` |
| `"{{20,111},{111}}"` | `[111, 20]` |
| `"{{123}}"` | `[123]` |
| `"{{4,2,3},{3},{2,3,4,1},{2,3}}"` | `[3, 2, 4, 1]` |

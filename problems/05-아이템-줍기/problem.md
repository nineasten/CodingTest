# [87694] 아이템 줍기

- 출처: 프로그래머스 · DFS/BFS
- URL: https://school.programmers.co.kr/learn/courses/30/lessons/87694
- 난이도: Lv.2 | 보드 칸: 2D 격자 L2

## 요약
격자 지도에서 시작점(0,0)부터 끝점까지 이동하되, 장애물이 없는 경로만 이용한다. 최단거리를 구한다 (BFS).

## 제약
- 격자 크기: 100×100 이내
- 장애물은 1, 통행 가능은 0으로 표시
- 상하좌우 4방향 이동만 가능
- 시작점: (0, 0), 끝점: (rows-1, columns-1)

## 목표 복잡도
O(N × M) — BFS로 모든 칸 방문 (최대 1회)

## 입출력 예시
- rectangle = [[0,0,2,2],[1,1,1,1]] (장애물 영역), target = [2,2] → 거리

(실제 문제는 직사각형 장애물 영역이 주어지고 이를 격자로 변환하는 부분이 있을 수 있음)

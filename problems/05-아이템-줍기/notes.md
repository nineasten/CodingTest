# [87694] 아이템 줍기 — 노트

- 난이도: Lv.2 | 유형: 2D 격자 + BFS
- 결과: 정확성 70% (테스트 18,19,22,24,25,27,28,29,30 실패) → 원인 규명 완료
- 힌트: 3/4
- 원인 태그: `#격자해상도누락`

## 문제의 핵심 제약 (여기서 모든 게 갈린다)

> 서로 다른 두 직사각형의 x축 좌표, 혹은 y축 좌표가 같은 경우는 없습니다

이 한 줄이 두 가지를 동시에 결정한다:
- 두 사각형이 **변을 공유하거나 꼭짓점에서만 만나는 입력은 존재하지 않음**
- 그러나 **좌표가 1만큼 차이 나는 건 허용됨** ← 이게 함정의 근원

## 내가 짠 로직 중 맞았던 것

```python
for x1,y1,x2,y2 in rectangle:      # 1패스: 모든 사각형 영역을 전부 1로
    ...map[x][y] = 1
for x1,y1,x2,y2 in rectangle:      # 2패스: 모든 사각형의 순수 내부를 0으로
    ...map[x][y] = 0
```

**두 루프를 분리한 것이 정답.** 사각형마다 "채우고-지우고"를 번갈아 했다면 틀렸다.
이 제약 하에서 "합집합의 내부 = 어떤 개별 사각형의 순수 내부"가 항상 성립하므로,
이 2패스 방식은 증명 가능하게 정확하다.

## 틀린 이유 — 로직이 아니라 "자의 눈금"

테두리는 굵기 0인 **선**인데, 정수 격자의 **칸**으로 표현했다.
좌표 간격이 1이면 사이에 정수 칸이 하나도 못 들어가므로,
기하학적으로 떨어져 있는 두 테두리가 격자에서는 **그냥 옆칸으로 붙어버린다.**
BFS는 그 틈을 1칸에 뛰어넘어 **존재하지 않는 지름길**을 만든다.

### 반례 (최소 형태)
```python
rectangle = [[3,1,4,7]]     # 폭이 1인 세로 막대
character = (3,3), item = (4,3)
```
- 내부 지우기가 `range(3+1, 4)` = **빈 범위** → 막대 전체가 1로 남음
- 내 코드: `(3,3) → (4,3)` 1칸에 관통 → **1 반환**
- 정답: 막대를 뚫을 수 없어 아래로 우회 2+1+2 = **5**

### 2배 확장하면
`[3,1,4,7]` → `[6,2,8,14]`. 내부 지우기가 `x=7, y=3..13`을 지워
**(7,6)에 진짜 벽이 생긴다.** 우회 10칸 → `10 // 2 = 5` ✓

## 왜 하필 2배인가
좌표가 전부 서로 다른 정수 → 두 테두리 사이 **최소 간격은 정확히 1**.
1은 "사이에 정수 칸이 하나도 못 들어가는" 유일한 간격이라, 2배만 하면
간격이 2가 되어 **반드시 빈 칸이 하나 끼어든다.** 3배·4배는 불필요.

## 수정 목록
1. 모든 좌표 2배 (`rectangle` 원소 + `characterX/Y` + `itemX/Y`), 반환 시 `// 2`
2. `map` 51×51 → **101×101** (좌표 최대 50 → 2배 100)
3. 범위 체크 상한 51 → **101** (하한은 `0 <=` 습관 들이기)
4. while 종료 후 `return -1` — 도넛 지형에서 `None` 반환 방지
5. 변수명 `map`은 내장 함수 섀도잉 (스타일)

## 비유 (다시 떠올릴 때)
1cm = 1km 축척 지도. 두 건물 사이 폭 1km 낭떠러지가 지도에선 딱 붙어 보인다.
"옆 건물이니 한 걸음"하고 발을 내디디면 추락. 모눈을 2배 촘촘히 그리면
낭떠러지 칸이 눈에 보이고, 걸음 수가 2배로 세어지니 마지막에 2로 나눈다.

# 프로그래머스 · 코딩테스트 연습
## [12930] 이상한 문자 만들기 (Lv.1)
https://school.programmers.co.kr/learn/courses/30/lessons/12930

**보드 칸**: 문자열 파싱 L1 | **목표**: 12분 / O(N)

---

## 문제 요약

문자열 s는 하나 이상의 단어로 구성되며, 단어는 하나 이상의 공백문자로 구분된다.
각 단어의 짝수 인덱스(0부터 시작) 알파벳은 대문자로, 홀수 인덱스 알파벳은 소문자로
바꾼 문자열을 반환한다. 인덱스는 단어별로 초기화된다(전체 문자열 기준 아님).

## 제약 조건

- 문자열 s의 길이: 1 ≤ len(s) ≤ 200
- s는 영문 알파벳(대소문자)과 공백으로 구성

## 입출력 예시

### 입력
```
"try hello world"
```

### 출력
```
"TrY HeLlO WoRlD"
```

---

## 풀이 목표

O(N) 시간복잡도로 풀기. 공백 기준 분리 후 단어별 인덱스 리셋에 주의.

# 풀이 기록

## 풀이 전략

원본 문자열을 한 번만 순회하며 인덱스를 직접 관리. 공백을 만나면 인덱스 리셋 +
공백 자체를 그대로 결과에 추가.

## 핵심

`split()`/`join()` 조합은 연속 공백·앞뒤 공백을 보존하지 못함 — 원본 구조를
유지해야 하는 문제는 인덱스 기반 1회 순회가 안전.

## 복잡도

- 시간: O(N)
- 공간: O(N)

## 결과

통과 (2/4 힌트 — 1단계 관찰(공백 보존 문제), 2단계 접근(1회 순회 방식))

## 교훈

문자열 분리 함수(split/join)는 편하지만 원본의 공백 구조 정보를 잃는다는 것을
항상 의심할 것.

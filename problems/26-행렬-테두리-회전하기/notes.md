# 행렬 테두리 회전하기 (77485)

## 접근
쿼리마다 테두리 좌표를 시계방향 순서로 나열 → 값들을 `deque.rotate(1)`로 한 칸씩 밀기 →
원래 값들 중 최솟값을 결과에 기록. 회전은 위치만 바꾸므로 min은 회전 전/후 값 집합이 같음.

## 막혔던 지점
1. `deque(...).rotate(1)`을 바로 변수에 대입 — `rotate()`는 in-place, 반환값 `None`.
2. `zip(indices, values)`에서 `indices` 원소가 `[x, y]` 쌍인데 `x, y, v`로 3개 언패킹 시도.
3. `maps` 생성 시 바깥/안쪽 컴프리헨션 축이 `columns`/`rows`와 반대로 들어가 있었음 —
   `rows == columns`면 안 터지고 실제로 다른 값(100, 97)으로 테스트해서야 발견.

## 복잡도
O(rows×columns + Q×(rows+columns)) — 목표 25분 내 3단계 힌트로 통과.

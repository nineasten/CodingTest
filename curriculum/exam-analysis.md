# 시험 분석 — 이 커리큘럼의 근거

2026-09-03에 조사한 실제 합격/응시 후기를 근거로 작성. 이 워크스페이스의 모든 비중·형식
결정(문제 은행 구성, 모의고사 형식, 훈련 비중)은 이 문서를 기준으로 한다.

## 1. 소프티어 부트캠프 1차 코딩테스트의 실체

| 항목 | 조사 결과 |
|---|---|
| 형식 | **5문항 / 2시간** |
| 커트라인 | 기수 편차 있으나 **2~3솔이면 통과** (난이도 높은 기수는 커트도 같이 낮아짐) |
| 출제 성향 | **"빡구현" 위주.** 최근 기수는 알고리즘 문제가 거의 없고 구현·시뮬레이션·조건분기 중심 |
| 고급 알고리즘 | **비중 낮음.** 4기 기준 다익스트라급은 요구되지 않았음 |
| 필요 자료구조 | 리스트·스택·큐를 정확히 다루는 수준. 복잡한 자료구조 아님 |
| 권장 도달선 | **프로그래머스 Lv.2 후반 ~ Lv.3 초반 안정적으로** (백준 실버~골드 초반) |
| 진짜 승부처 | **시간 관리와 정확도.** 한 문제가 길어서 시간을 많이 먹음 → 입출력 처리와 엣지케이스 |
| 2차 | 코딩테스트가 아니라 **CS 전공지식 평가** |

## 2. 전략적 결론 — 커리큘럼 설계 원칙

1. **"어려운 알고리즘"을 파는 건 가성비가 나쁘다.** 승부는 *긴 조건 명세를 실수 없이
   코드로 옮기는 속도*에서 난다. 훈련 비중:

   | 비중 | 영역 |
   |---|---|
   | **40%** | 구현 · 시뮬레이션 · 2D 격자 · 문자열 파싱 |
   | **25%** | 자료구조(스택/큐/힙/해시) + 정렬 |
   | **20%** | BFS/DFS · 완전탐색 · 백트래킹 |
   | **15%** | 그리디 · 이분탐색 · DP 기초 (Lv.3 초반까지만) |

   플로이드·세그먼트 트리·고급 DP는 **버린다.** 4주 안에 안 나올 것에 쓸 시간이 없다.

2. **"2~3솔 통과"는 곧 문제 선별 능력이 점수다.** 5문제 중 풀 수 있는 3개를 빨리
   골라내고, 안 되는 2개를 과감히 버리는 훈련이 필요하다. → `/mock`은 실제 형식대로
   5문항 2시간으로 맞추고, 리뷰에 "문제 선택이 옳았는가"를 항상 넣는다.

3. **엣지케이스에서 감점된다.** 로컬 채점기가 없으므로, 리뷰에서 반례를 논리로
   짚어내는 것이 이 워크스페이스의 핵심 기능이 된다.

4. **2차 CS 대비도 미리 씨를 뿌린다.** 매 문제 회고에서 쓴 자료구조의 동작 원리를
   한 줄씩 `INSIGHTS.md`에 적립해 4주 뒤 CS 답변 소재로 재활용한다.

## 3. LG Aimers는 코딩테스트 시험이 아니다

LG Aimers는 **온라인 AI 강의(1개월) + LG 산업 데이터 해커톤(1개월)** 구조다.
제조 공정 최적화·불량 예측 같은 **정형데이터 예측 대회**이며, Public/Private
스코어로 순위가 갈린다. 알고리즘 코딩테스트가 아니다.

> **이 워크스페이스는 소프티어 대비에 집중한다.** LG Aimers는 pandas/scikit-learn·
> EDA·피처 엔지니어링·검증 전략이라는 완전히 다른 트랙이므로, 4주 소프티어 대비를
> 끝낸 뒤 별도 워크스페이스로 준비할 것을 권한다.

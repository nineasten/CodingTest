# 해시

## 1. 언제 이 기술인가 — 문제 속 신호
"존재하는지 빠르게 확인", "짝을 찾아라", "몇 번 등장했는지", "중복을 제거" — 완전탐색으로
O(N²)가 되는 문제를 O(N)으로 줄일 수 있는지 항상 먼저 의심한다.

## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 짝을 찾는 문제 (한쪽 리스트에서 다른 쪽을 뺐을 때 남는 것)
Counter의 뺄셈은 음수를 버리므로 "이쪽엔 있는데 저쪽엔 없는 것"을 구할 때 편하다.
```python
from collections import Counter
diff = Counter(participants) - Counter(completed)
answer = list(diff.keys())[0]
```

### 상황 B: 여러 값을 조합해 만들 수 있는 경우의 수
각 카테고리에서 하나씩 고르거나 안 고르는 조합 — "의상"류. `(개수+1)`을 곱하고
"아무것도 안 입는 경우"를 빼는 패턴이 전형적이다.
```python
from collections import defaultdict
cnt = defaultdict(int)
for name, category in clothes:
    cnt[category] += 1
result = 1
for c in cnt.values():
    result *= (c + 1)
answer = result - 1   # 아무것도 안 고르는 경우 제외
```

### 상황 C: 키를 조합해서 만들어야 할 때 (여러 값을 묶어 하나의 키로)
```python
key = (a, b)          # 튜플은 dict/set의 키로 바로 쓸 수 있음
key = f"{a}_{b}"       # 또는 문자열로 합쳐도 됨 (구분자 충돌 주의)
```

## 3. 자주 하는 실수
- 정렬로 풀 수 있는 문제를 해시로 접근해 코드가 오히려 복잡해짐 — "짝 맞추기"는 정렬도 답
- dict의 키가 리스트(mutable)라 TypeError — 키는 반드시 불변 타입(튜플, 문자열, 숫자)
- Counter 뺄셈이 음수를 버린다는 걸 몰라서 다른 방식으로 우회함 — 상황 A 패턴을 기억

## 4. Python 잡기술
- `Counter(a) - Counter(b)`, `Counter(a) & Counter(b)`(교집합, 최솟값), `Counter(a) | Counter(b)`(합집합, 최댓값)
- `set(a) & set(b)`, `set(a) | set(b)`, `set(a) - set(b)` — 집합 연산 전체

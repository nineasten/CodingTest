# 해시

## 1. 언제 이 기술인가 — 문제 속 신호
"존재하는지 빠르게 확인", "짝을 찾아라", "몇 번 등장했는지", "중복을 제거" — 완전탐색으로
O(N²)가 되는 문제를 O(N)으로 줄일 수 있는지 항상 먼저 의심한다.

## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 짝을 찾는 문제 (한쪽 리스트에서 다른 쪽을 뺐을 때 남는 것)
마라톤 참가자 명단 `["leo","kiki","eden"]`과 완주자 명단 `["eden","kiki"]`이 주어지고,
"완주하지 못한 선수"를 찾아야 한다. 동명이인이 있을 수도 있어 `set` 차집합은 위험하다
(개수 차이를 무시해버림). `Counter`끼리 빼면 "개수까지 고려한 차이"가 남고, 음수가
되는 쪽(완주자에만 있는 경우, 정상적으론 안 생김)은 자동으로 버려진다.
```python
from collections import Counter
participant = ["leo", "kiki", "eden"]
completion = ["eden", "kiki"]
diff = Counter(participant) - Counter(completion)   # Counter({'leo': 1})
answer = list(diff.keys())[0]                        # "leo"
```

### 상황 B: 여러 값을 조합해 만들 수 있는 경우의 수
옷장에 `[("yellow_hat","hat"), ("blue_sunglasses","eyewear"), ("green_turban","hat")]`
처럼 (이름, 카테고리)가 있고, "종류별로 최대 한 개씩 골라 입는 조합이 몇 가지인가"를
구한다고 하자("의상"류). 카테고리가 "hat"이 2개, "eyewear"가 1개면, 각 카테고리에서
"그 중 하나를 고르거나, 아무것도 안 고르거나" — 즉 (개수+1)가지 선택이 있다. 카테고리별
선택지를 곱한 뒤, "모든 카테고리에서 하나도 안 고르는 경우"(옷을 하나도 안 입는 경우,
문제에서 제외됨) 1가지를 빼준다.
```python
from collections import defaultdict
cnt = defaultdict(int)
for name, category in [("yellow_hat","hat"), ("blue_sunglasses","eyewear"), ("green_turban","hat")]:
    cnt[category] += 1
# cnt = {"hat": 2, "eyewear": 1}
result = 1
for c in cnt.values():
    result *= (c + 1)   # hat: 2+1=3가지(안쓰기/노랑/초록), eyewear: 1+1=2가지
answer = result - 1     # 3*2 - 1 = 5 (아무것도 안 입는 경우 제외)
```

### 상황 C: 키를 조합해서 만들어야 할 때 (여러 값을 묶어 하나의 키로)
좌표 `(2, 3)`처럼 값 두 개를 묶어야 dict/set에 넣을 수 있는 "하나의 정체성"이 되는
경우가 많다. 예를 들어 "(이름, 생일)이 정확히 같은 사람이 몇 명인지" 세려면 이름과
생일을 각각 따로 세면 안 되고 묶어서 하나의 키로 취급해야 한다.
```python
key = ("kim", "0101")   # 튜플은 dict/set의 키로 바로 쓸 수 있음(불변이라 해시 가능)
key2 = f"kim_0101"       # 또는 문자열로 합쳐도 됨 (구분자가 실제 값에 안 나오게 주의)
cnt = defaultdict(int)
cnt[("kim", "0101")] += 1
```

## 3. 자주 하는 실수
- 정렬로 풀 수 있는 문제를 해시로 접근해 코드가 오히려 복잡해짐 — "짝 맞추기"는 정렬도 답
- dict의 키가 리스트(mutable)라 TypeError — 키는 반드시 불변 타입(튜플, 문자열, 숫자)
- Counter 뺄셈이 음수를 버린다는 걸 몰라서 다른 방식으로 우회함 — 상황 A 패턴을 기억

## 4. Python 잡기술
- `Counter(a) - Counter(b)`, `Counter(a) & Counter(b)`(교집합, 최솟값), `Counter(a) | Counter(b)`(합집합, 최댓값)
- `set(a) & set(b)`, `set(a) | set(b)`, `set(a) - set(b)` — 집합 연산 전체

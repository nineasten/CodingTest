# 완전탐색 · 백트래킹

## 1. 언제 이 기술인가 — 문제 속 신호
"가능한 모든 경우를 확인", "N이 작다(≤11이면 순열, ≤20이면 부분집합)", "조건을 만족하는
배치를 찾아라"(N-Queen류). 03번(복잡도감각) 표로 N을 보고 "이거 완전탐색으로 되겠다"를
먼저 판단하는 게 시작점.

## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 모든 순열을 시도 (순서가 의미 있을 때)
```python
from itertools import permutations
for perm in permutations(arr):       # arr의 모든 순서 조합
    ...
```

### 상황 B: 모든 조합을 시도 (순서 무관, 몇 개를 고를지 정해짐)
```python
from itertools import combinations
for combo in combinations(arr, r):   # arr에서 r개를 고르는 모든 방법
    ...
```

### 상황 C: 모든 부분집합을 시도 (2^N)
비트마스크로 "이 원소를 포함하는가"를 이진수 하나로 표현하면 코드가 짧아진다.
```python
n = len(arr)
for mask in range(1 << n):           # 0 ~ 2^n - 1
    subset = [arr[i] for i in range(n) if mask & (1 << i)]
```

### 상황 D: 조건에 안 맞으면 즉시 포기 (가지치기 = 백트래킹)
N-Queen류 — 다 만들고 나서 검사하면 느리다. **한 칸씩 놓을 때마다 바로 유효성을 확인**하고,
안 되면 그 갈래를 아예 만들지 않는다.
```python
def backtrack(row, cols, diag1, diag2):
    if row == n:
        nonlocal count
        count += 1
        return
    for col in range(n):
        if col in cols or (row-col) in diag1 or (row+col) in diag2:
            continue                          # 가지치기: 여기서 즉시 포기
        cols.add(col); diag1.add(row-col); diag2.add(row+col)
        backtrack(row+1, cols, diag1, diag2)
        cols.remove(col); diag1.remove(row-col); diag2.remove(row+col)  # 되돌리기 필수
```

### 상황 E: 격자/도형을 겹쳐보며 맞는 배치를 찾기 (카펫류)
"가능한 가로·세로 조합을 다 시도해 조건을 만족하는 것 찾기" — 조건(가로*세로=넓이 등)으로
후보를 먼저 좁힌 뒤 완전탐색하면 훨씬 빠르다.

## 3. 자주 하는 실수
- 백트래킹에서 **되돌리기(상태 원복)를 빼먹음** — 다음 갈래를 탐색할 때 이전 선택이
  남아있어 오답
- `permutations`/`combinations`를 리스트로 바로 변환해 메모리를 낭비 — 필요할 때만 순회
- N이 20을 넘는데 완전탐색을 시도 — 03번 표를 다시 확인하고 접근을 바꿀 것

## 4. Python 잡기술
- `itertools.product(*iterables)` — 여러 리스트에서 하나씩 골라 만드는 모든 조합 (중복 허용)
- `itertools.combinations_with_replacement` — 같은 원소를 여러 번 골라도 되는 조합

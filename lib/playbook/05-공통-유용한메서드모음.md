# 유용한 메서드 모음 — 타입별 참조표

## 1. 언제 이 노트인가
다른 노트는 "이 상황엔 이 코드"로 상황별로 흩어져 있다. 이 노트는 반대로 **타입별로
모아놓은 사전**이다. "문자열에 이런 것도 되나?" 싶을 때 찾아본다. 외울 필요는 없고,
코딩 중 막히면 여기부터 훑는다.

## 2. 문자열 (str) — 값을 바꿀 수 없다(불변), 메서드는 항상 "새 문자열"을 돌려준다

| 메서드 | 하는 일 | 예시 |
|---|---|---|
| `s.split(sep)` | sep 기준으로 나눠 리스트로 | `"a,b,c".split(",")` → `['a','b','c']` |
| `s.split()` | 인자 없으면 공백(연속 공백도 하나로) 기준 | `"a  b".split()` → `['a','b']` |
| `sep.join(list)` | 리스트를 sep으로 이어붙여 문자열로 | `','.join(['a','b'])` → `"a,b"` |
| `s.strip()` | 앞뒤 공백/개행 제거 | `" hi \n".strip()` → `"hi"` |
| `s.replace(a, b)` | a를 b로 전부 치환 | `"aab".replace("a","x")` → `"xxb"` |
| `s.find(x)` | x의 첫 위치, 없으면 -1 (에러 안 남) | `"abc".find("b")` → `1` |
| `s.index(x)` | find와 같지만 없으면 에러 (ValueError) | |
| `s.count(x)` | x가 몇 번 나오는지 | `"aaba".count("a")` → `3` |
| `s.upper()` / `.lower()` | 대문자/소문자로 | |
| `s.isdigit()` | 숫자로만 이루어졌는지 (True/False) | |
| `s.isalpha()` | 알파벳으로만 이루어졌는지 | |
| `s.startswith(x)` / `.endswith(x)` | 접두/접미 확인 | |
| `s.zfill(n)` | 왼쪽을 0으로 채워 길이 n으로 | `"5".zfill(3)` → `"005"` |
| `ord(c)` / `chr(n)` | 문자→아스키코드 / 코드→문자 | `ord('a')`→97, `chr(97)`→`'a'` |

## 3. 리스트 (list) — 값을 바꿀 수 있다(가변)

| 메서드 | 하는 일 | 반환값 |
|---|---|---|
| `arr.append(x)` | 맨 뒤에 x 하나 추가 | None (자기 자신이 바뀜) |
| `arr.extend(other)` | 맨 뒤에 other의 원소들을 풀어서 추가 | None |
| `arr.insert(i, x)` | i번 위치에 x 삽입 | None |
| `arr.remove(x)` | x와 같은 첫 원소를 삭제 (값으로 찾음) | None, 없으면 에러 |
| `arr.pop()` / `arr.pop(i)` | 맨 뒤(또는 i번) 원소를 꺼내며 삭제 | 꺼낸 값 |
| `arr.index(x)` | x가 처음 나오는 인덱스 | 인덱스, 없으면 에러 |
| `arr.count(x)` | x의 개수 | 개수 |
| `arr.reverse()` | 자기 자신을 뒤집음 | None |
| `arr[::-1]` | 뒤집은 **새 리스트**를 만듦 (원본 유지) | 새 리스트 |
| `arr.copy()` | 얕은 복사본 | 새 리스트 |
| `sum(arr)` / `max(arr)` / `min(arr)` | 합/최댓값/최솟값 | 값 |
| `x in arr` | 포함 여부 (리스트는 O(N), 크면 느림 — 02번 노트 참고) | True/False |

`append`/`extend` 차이: `[1,2].append([3,4])` → `[1,2,[3,4]]` (통째로 하나 추가),
`[1,2].extend([3,4])` → `[1,2,3,4]` (풀어서 추가).

## 4. 딕셔너리 (dict)

| 메서드 | 하는 일 | 예시 |
|---|---|---|
| `d.get(k, default)` | 키 k의 값, 없으면 default (에러 안 남) | `d.get("x", 0)` |
| `d[k]` | 키 k의 값, 없으면 KeyError | |
| `d.keys()` / `.values()` / `.items()` | 키들 / 값들 / (키,값) 쌍들 | `for k, v in d.items():` |
| `k in d` | 키가 존재하는지 | True/False |
| `d.pop(k)` | 키 k를 꺼내며 삭제 | 그 값 |
| `d.setdefault(k, default)` | 키 있으면 값 반환, 없으면 default로 설정 후 반환 | |
| `d.update(other)` | other 딕셔너리 내용을 병합 | None |

## 5. 집합 (set) — 순서 없음, 중복 없음

| 메서드 | 하는 일 |
|---|---|
| `s.add(x)` | 원소 추가 |
| `s.remove(x)` | 삭제, 없으면 에러 / `s.discard(x)`는 없어도 에러 안 남 |
| `a & b` | 교집합 (`a.intersection(b)`) |
| `a \| b` | 합집합 (`a.union(b)`) |
| `a - b` | 차집합 (`a.difference(b)`) |
| `a <= b` | a가 b의 부분집합인지 (`a.issubset(b)`) |

## 6. 자주 쓰는 내장 함수 (타입 무관)

| 함수 | 하는 일 |
|---|---|
| `sum(iterable)` | 합계. `sum(arr, start)`로 시작값도 지정 가능 |
| `max(iterable)` / `min(iterable)` | 최댓값/최솟값. `key=` 옵션으로 기준 지정 가능 |
| `abs(x)` | 절댓값 |
| `round(x, n)` | 소수점 n자리 반올림 |
| `all(iterable)` | 전부 참이면 True (하나라도 거짓이면 False) |
| `any(iterable)` | 하나라도 참이면 True |
| `reversed(x)` | 뒤집힌 순회객체 (리스트로 보려면 `list(reversed(x))`) |
| `sorted(x, key=, reverse=)` | 정렬된 새 리스트 (03번 노트 참고) |
| `divmod(a, b)` | `(a//b, a%b)`를 한 번에 |

## 7. 자주 하는 실수
- `.remove()`는 **값**으로 찾아 지우고, `.pop(i)`는 **인덱스**로 지운다 — 헷갈리면
  엉뚱한 원소가 삭제됨
- `d[k]`로 없는 키에 접근해 `KeyError` — 있을지 확신 없으면 `.get()` 사용
- `s.find()`는 없으면 -1을 돌려줄 뿐 에러가 안 나서, 이걸 `if s.find(x):`처럼 참/거짓
  판단에 잘못 쓰면 버그 (0번 인덱스에서 찾아도 `if 0:`은 False로 취급됨) — 반드시
  `if s.find(x) != -1:`처럼 명시 비교

# 공통: 입출력과 파싱

## 1. 언제 이 기술인가 — 문제 속 신호
모든 문제. 특히 "여러 줄에 걸쳐 입력이 주어진다", "공백으로 구분된", "각 줄은 ~형식이다"
같은 문구가 나오면 파싱 실수부터 의심한다. 소프티어·백준형 stdin 문제에서 특히 중요.
(프로그래머스는 대부분 함수 인자로 주므로 이 노트는 백준형/모의고사 대비용.)

## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 한 줄에 여러 정수, 공백 구분
예를 들어 문제 첫 줄이 `5 3`이면, 도시가 5개고 도로가 3개라는 뜻으로 보통 `n, m`
이렇게 두 값으로 나눠 받아야 한다. `split()`은 공백이 몇 칸이든(`5   3`처럼 여러 칸이어도)
알아서 나눠주므로 구분자 걱정 없이 안전하다.
```python
import sys
input = sys.stdin.readline
n, m = map(int, input().split())
```
`map(int, ...)`이 문자열 `"5"`, `"3"`을 각각 정수로 바꾸고, 그걸 `n, m`에 순서대로
나눠 담는다.

### 상황 B: N줄에 걸쳐 정수 하나씩
첫 줄에 `n=3`이 오고, 그 다음 세 줄에 걸쳐 점수가 `90`, `85`, `77`처럼 한 줄에 하나씩
나온다고 하자. `input()`을 N번 부르는 건 N이 작을 땐 문제없지만 10만 줄쯤 되면 그
자체가 병목이 된다. `sys.stdin.readline`으로 고정하고, 문자열 비교가 필요한 경우엔
줄 끝에 남는 개행(`\n`)을 `.strip()`으로 지운다.
```python
import sys
input = sys.stdin.readline
arr = [int(input()) for _ in range(n)]   # [90, 85, 77]
```

### 상황 C: 한 줄에 N개의 정수가 있는 배열
`"3 1 4 1 5"`처럼 한 줄 전체가 배열 하나를 나타내는 경우. 앞의 두 상황과 코드는
같은 모양이지만 여기선 **개수(n)를 몰라도** 그 줄에 있는 만큼 다 읽는다.
```python
arr = list(map(int, input().split()))   # [3, 1, 4, 1, 5]
```

### 상황 D: 남은 입력을 한꺼번에 다 읽어야 할 때 (입력량이 매우 많을 때)
줄 수가 수만~수십만에 달하는 문제에서 `readline`을 그만큼 반복 호출하는 것도 느리게
느껴질 수 있다. 이럴 땐 `sys.stdin.read()`로 입력 전체를 문자열 하나로 통째로 읽고,
공백 기준으로 다 쪼갠 뒤 순서대로 필요한 만큼 꺼내 쓰는 게 가장 빠르다.
```python
import sys
data = sys.stdin.read().split()   # 파일 전체가 토큰 리스트 하나로
idx = 0
n = int(data[idx]); idx += 1
arr = list(map(int, data[idx:idx+n])); idx += n   # n개를 꺼내고 idx를 그만큼 전진
```
"지금까지 어디까지 읽었는지"를 `idx` 하나로 계속 들고 다니는 게 이 패턴의 핵심이다.

### 상황 E: 문자열 한 줄 (개행 제거 필수)
예를 들어 `input()`으로 이름 하나를 읽으면 실제로는 `"kim\n"`처럼 줄바꿈이 붙어서
들어온다. 이 상태로 `"kim" == 이름`을 비교하면 항상 거짓이 나와 원인 모를 버그가 된다.
```python
s = input().strip()   # "kim\n" → "kim"
```

### 상황 F: 출력이 많을 때 (수만 줄)
결과를 한 줄씩 수만 번 `print`하면 그 자체가 시간초과의 원인이 될 수 있다. 결과를
리스트에 차곡차곡 모아뒀다가 마지막에 개행으로 이어붙여 **딱 한 번만** 출력한다.
```python
out = []
for r in results:
    out.append(str(r))
print('\n'.join(out))   # print를 N번이 아니라 1번만 호출
```

## 3. 자주 하는 실수
- `input()`을 그냥 쓰다가 N이 커서 시간초과 — 항상 `sys.stdin.readline`으로 바꿀 것
- 문자열 비교인데 개행 문자를 안 지워서 틀림 (`"abc\n" != "abc"`) → `.strip()`
- `split()`에 구분자를 잘못 지정 (콤마인데 공백 기준으로 나눔 등) → 문제 예제를 먼저 확인

## 4. Python 잡기술
- `map(int, line.split())`은 제너레이터이므로 여러 번 순회하려면 `list()`로 감쌀 것
- 입력이 없을 수도 있는 줄(빈 줄)은 `line.split()`이 빈 리스트를 주는 것을 이용해 처리

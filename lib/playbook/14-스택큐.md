## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 괄호/짝 맞추기 (스택의 전형)
`"({[]})"`처럼 여러 종류의 괄호가 섞인 문자열이 올바르게 짝지어졌는지 검사한다고 하자.
여는 괄호는 만날 때마다 스택에 쌓고, 닫는 괄호를 만나면 "지금 스택 맨 위(가장 최근에
연 괄호)와 짝이 맞는가"만 확인하면 된다 — 가장 최근 것부터 닫혀야 하므로 스택(LIFO)이
정확히 이 문제의 구조와 맞아떨어진다.
```python
def matches(open_ch, close_ch):
    return {'(':')', '[':']', '{':'}'}[open_ch] == close_ch

stack = []
for ch in "({[]})":
    if ch in '([{':
        stack.append(ch)          # 여는 괄호는 일단 쌓아둠
    else:
        if not stack or not matches(stack.pop(), ch):
            print(False); break   # 짝이 안 맞거나 꺼낼 게 없으면 바로 실패
else:
    print(not stack)   # 끝까지 다 돌았는데 스택이 비었으면 완전히 짝이 맞은 것
```

### 상황 B: 대기열 시뮬레이션 (큐)
인쇄 대기열에 우선순위가 `[2, 1, 3, 2]`인 문서 4개가 순서대로 쌓여있다고 하자
("프로세스/프린터"류). 맨 앞 문서를 꺼냈을 때, **대기열에 남은 문서 중 우선순위가
더 높은 게 하나라도 있으면** 지금 꺼낸 문서를 다시 맨 뒤로 보내고 기다려야 한다.
```python
from collections import deque
priorities = [2, 1, 3, 2]
q = deque(enumerate(priorities))   # [(0,2), (1,1), (2,3), (3,2)] — (원래인덱스, 값)
order = []
while q:
    idx, val = q.popleft()
    if any(val < other for _, other in q):   # 남은 문서 중 더 급한 게 있으면
        q.append((idx, val))                  # 다시 맨 뒤로 보냄
    else:
        order.append(idx)                     # 지금 인쇄
# order = [2, 0, 3, 1] — 3번째(우선순위3)가 가장 먼저, 그다음 1번째...
```

### 상황 C: "다음의 더 큰/작은 값"을 찾는 문제 (모노토닉 스택)
"주식가격" 문제처럼 `[1, 2, 3, 2, 3]`(초 단위 가격)이 주어지고, "각 시점의 가격이
떨어지지 않은 채로 유지된 시간(초)"을 구해야 한다고 하자. i번째 가격이 언제 처음
자기보다 더 낮은/큰 값을 만나는지를 매번 뒤를 다 훑으면 O(N²)이다. 대신 스택에
"아직 답이 안 정해진 인덱스"만 쌓아두고, 지금 값이 스택 맨 위 인덱스의 값보다 크면
그 인덱스의 답이 바로 확정된다(이중 for문을 O(N)으로 줄이는 핵심 트릭).
```python
arr = [1, 2, 3, 2, 3]
stack = []          # 아직 "더 큰 값을 못 만난" 인덱스들
answer = [0] * len(arr)
for i, val in enumerate(arr):
    while stack and arr[stack[-1]] < val:
        j = stack.pop()
        answer[j] = i - j   # j번째가 (i-j)칸 뒤에서 자기보다 큰 값을 처음 만남
    stack.append(i)
# 루프가 끝난 뒤 스택에 남은 인덱스는 "끝까지 더 큰 값을 못 만난" 것 → 별도 처리 필요
```

### 상황 D: 트럭/컨베이어처럼 "몇 초 뒤 빠진다"를 다루는 시뮬레이션
길이 2인 다리에 무게 10, 10인 트럭 두 대가 순서대로 건너야 한다고 하자("다리를
지나는 트럭"류). 다리 위에 있는 트럭들은 "몇 초 뒤에 다리를 벗어나는지"가 이미
정해져 있으므로, 큐에 (벗어날 시각, 무게)를 넣어두고 매 초 맨 앞부터 확인하면서
빼면 된다.
```python

bridge = deque()   # 다리 위 트럭들의 (탈출시각, 무게)
time = 0
weight_on_bridge = 0

    time += 1
    if bridge and bridge[0][0] == time:      # 맨 앞 트럭이 지금 다리를 벗어남
        _, w = bridge.popleft()
        weight_on_bridge -= w

```

## 3. 자주 하는 실수
- 큐를 `list`로 만들고 `pop(0)` 사용 — O(N)이라 시간초과. **deque 필수**
- 스택이 비었는지 확인 안 하고 `pop()` — IndexError. 항상 `if stack:` 먼저 체크
- 우선순위 큐가 필요한데 일반 큐/리스트로 매번 최댓값을 선형 탐색 — 힙(15번 노트)으로 바꿀 것

## 4. Python 잡기술
- `deque.rotate(n)` — 큐를 n칸 회전 (원형 큐 시뮬레이션에 유용)
- 인덱스와 값을 함께 넣기: `deque(enumerate(arr))` — 원래 순서를 잃지 않고 처리

# 구현 · 시뮬레이션 ★ 시험 최다 출제

## 1. 언제 이 기술인가 — 문제 속 신호
"다음 규칙에 따라 진행한다", "순서대로 처리한다", "각 단계마다", "조건을 만족하면 ~한다"
처럼 **알고리즘 이론이 아니라 문제에 적힌 절차를 그대로 코드로 옮기면 되는 문제**.
소프티어 코딩테스트의 주력 유형 — 어려운 자료구조보다 **긴 조건을 빠짐없이, 정확히**
옮기는 능력이 관건이다.

## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 조건이 여러 개 순서대로 적용되는 문제 (연쇄 규칙)
"신규 아이디 추천"류 — 규칙이 1단계→2단계→...→7단계로 나열되는 문제. **함수를 규칙
하나당 하나씩 쪼개서** 순서대로 적용하면 실수가 줄어든다. 한 함수에 다 우겨넣지 말 것.
```python
def step1(s): ...
def step2(s): ...
def solution(new_id):
    s = new_id
    for step in (step1, step2, step3, step4, step5, step6, step7):
        s = step(s)
    return s
```

### 상황 B: 상태를 유지하며 이벤트를 순서대로 처리
"큐에 사람이 들어오고 나간다", "시간이 지날 때마다 상태가 바뀐다" 류. **상태를 변수(또는
작은 dict/class)로 명확히 정의**하고, 이벤트 루프 안에서 상태만 갱신한다.
```python
state = {"time": 0, "queue": deque(), "count": 0}
for event in events:
    if event == "in":
        state["queue"].append(...)
    elif event == "out":
        state["queue"].popleft()
    state["time"] += 1
```

### 상황 C: 문자열을 규칙에 따라 변환/파싱
쉼표·괄호·구분자로 중첩된 구조를 해석하는 문제("튜플" 류). 문자열을 직접 슬라이싱하기보다
**정규식(`re`) 또는 `split`을 단계적으로 적용**하면 안전하다.
```python
import re
tokens = re.findall(r'\{[\d,]*\}', s)   # {1,2,3} 형태를 통째로 추출
```

### 상황 D: 시뮬레이션 도중 "종료 조건"을 놓치기 쉬운 문제
반복이 언제 끝나는지(모든 원소가 처리됨, 더 이상 변화가 없음, 특정 횟수 도달)를 **루프
시작 전에 먼저 글로 적어보고** 코드로 옮긴다. 조건을 코드 짜면서 즉흥적으로 정하면 꼭
한 케이스가 빠진다.
```python
while queue:                 # "큐가 빌 때까지" — 명시적 종료조건
    ...
```

### 상황 E: 여러 그룹/카테고리별로 집계해야 하는 문제
"성격 유형 검사하기"류 — 카테고리별 점수를 누적하고 마지막에 비교. `defaultdict`로
누적하고, 동점 처리 규칙을 문제에서 반드시 다시 확인한다(사전순 우선인지, 큰 값 우선인지).
```python
from collections import defaultdict
score = defaultdict(int)
for answer in answers:
    score[category(answer)] += weight(answer)
```

## 3. 자주 하는 실수
- **문제를 처음 읽을 때 조건 하나를 놓침** — 조건이 5개 이상이면 각 조건을 번호 매겨
  체크리스트로 옮겨 적고, 코드에서 그 번호를 주석으로 남긴다
- 0-index / 1-index 혼동 — 문제가 "1번째"라고 하면 배열 인덱스와 하나씩 어긋남
- 동점·경계값 처리 규칙을 문제 뒷부분(제약조건, 예시 설명)에서 놓침 — 예시를 반드시
  손으로 한 번 따라가 볼 것
- 원본 리스트를 순회하면서 그 리스트를 직접 수정 — 복사본을 만들거나 인덱스를 거꾸로 순회

## 4. Python 잡기술
- `enumerate(arr, start=1)` — 1-index로 세고 싶을 때 바로 사용
- `str.translate`, `re.sub` — 문자 단위 변환을 반복문 없이 한 번에
- `all(...)`, `any(...)` — 여러 조건을 동시에 확인할 때 for문보다 짧고 명확
- `itertools.groupby` — 연속된 같은 값을 그룹으로 묶을 때 (정렬 후에만 의미 있음)

# 공통: 입출력과 파싱

## 1. 언제 이 기술인가 — 문제 속 신호
모든 문제. 특히 "여러 줄에 걸쳐 입력이 주어진다", "공백으로 구분된", "각 줄은 ~형식이다"
같은 문구가 나오면 파싱 실수부터 의심한다. 소프티어·백준형 stdin 문제에서 특히 중요.
(프로그래머스는 대부분 함수 인자로 주므로 이 노트는 백준형/모의고사 대비용.)

## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 한 줄에 여러 정수, 공백 구분
가장 흔한 패턴. `split()`은 공백 개수와 무관하게 알아서 나눠주므로 안전하다.
```python
import sys
input = sys.stdin.readline
n, m = map(int, input().split())
```

### 상황 B: N줄에 걸쳐 정수 하나씩
`input()`을 N번 부르는 건 사소해 보여도 N이 크면(10만+) 느리다. `sys.stdin.readline`으로
고정하고, 개행 문자(`\n`)가 남는 상황(문자열 비교 시)엔 `.strip()`을 잊지 않는다.
```python
import sys
input = sys.stdin.readline
arr = [int(input()) for _ in range(n)]
```

### 상황 C: 한 줄에 N개의 정수가 있는 배열
```python
arr = list(map(int, input().split()))
```

### 상황 D: 남은 입력을 한꺼번에 다 읽어야 할 때 (입력량이 매우 많을 때)
`readline`을 반복 호출하는 것보다 `sys.stdin.read()`로 통째로 읽고 나눠 쓰는 게 빠르다.
```python
import sys
data = sys.stdin.read().split()
idx = 0
n = int(data[idx]); idx += 1
arr = list(map(int, data[idx:idx+n])); idx += n
```

### 상황 E: 문자열 한 줄 (개행 제거 필수)
```python
s = input().strip()
```

### 상황 F: 출력이 많을 때 (수만 줄)
`print`를 반복 호출하면 느리다. 리스트에 모았다가 한 번에 출력한다.
```python
out = []
out.append(str(result))
print('\n'.join(out))
```

## 3. 자주 하는 실수
- `input()`을 그냥 쓰다가 N이 커서 시간초과 — 항상 `sys.stdin.readline`으로 바꿀 것
- 문자열 비교인데 개행 문자를 안 지워서 틀림 (`"abc\n" != "abc"`) → `.strip()`
- `split()`에 구분자를 잘못 지정 (콤마인데 공백 기준으로 나눔 등) → 문제 예제를 먼저 확인

## 4. Python 잡기술
- `map(int, line.split())`은 제너레이터이므로 여러 번 순회하려면 `list()`로 감쌀 것
- 입력이 없을 수도 있는 줄(빈 줄)은 `line.split()`이 빈 리스트를 주는 것을 이용해 처리

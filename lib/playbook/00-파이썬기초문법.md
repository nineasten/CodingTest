# 파이썬 기초 문법 — 여기서부터 다시 시작

## 1. 언제 이 노트인가
다른 모든 playbook 노트는 "이 상황엔 이 코드"를 보여주는데, 그 코드 안에 나오는
`map`, `lambda`, `[::-1]`, 함수 정의 문법 자체가 낯설면 코드를 봐도 뭘 하는지 모른다.
**오래 코딩을 쉬어서 감이 없을 때 제일 먼저 읽는 노트.** 여기서 기본기를 다지고 나서
01번(입출력) 이후를 보면 코드가 읽힌다.

## 2. 변수와 자료형 — "값에 이름표를 붙인다"

파이썬은 변수를 선언할 때 타입을 안 적는다. `=`으로 값을 대입하면 그 타입이 자동으로
정해진다.
```python
n = 5           # int (정수)
pi = 3.14       # float (실수)
name = "kim"    # str (문자열)
is_ok = True    # bool (참/거짓)
arr = [1, 2, 3] # list (여러 값을 순서대로 담는 상자)
```
`type(변수)`로 지금 타입이 뭔지 확인할 수 있다. `print(type(n))` → `<class 'int'>`.

## 3. 함수 — "입력을 받아 출력을 돌려주는 상자"

### 함수 정의 문법
```python
def 함수이름(매개변수1, 매개변수2):
    # 함수 안에서 할 일
    결과 = 매개변수1 + 매개변수2
    return 결과       # return이 있어야 값을 "돌려준다". 없으면 None을 돌려줌

value = 함수이름(3, 4)   # 이렇게 "호출"하면 매개변수 자리에 3, 4가 들어가서 실행됨
print(value)             # 7
```
- **매개변수(parameter)** = 함수를 정의할 때 적는 자리, **인자(argument)** = 함수를
  호출할 때 실제로 넘기는 값. "인자로 뭐가 들어오는가"는 곧 "호출할 때 괄호 안에
  뭘 넣느냐"다.
- 프로그래머스 문제는 대부분 `def solution(매개변수들):` 형태로 함수가 이미 주어지고,
  그 안을 채우는 방식이다. **`solution`의 매개변수 이름과 타입(리스트인지 숫자인지
  문자열인지)을 문제 설명에서 먼저 확인**하는 게 시작점.

### 기본값이 있는 매개변수
```python
def greet(name, greeting="안녕"):   # greeting을 안 주면 "안녕"이 자동으로 들어감
    return f"{greeting}, {name}"
greet("철수")             # "안녕, 철수"
greet("철수", "반가워")    # "반가워, 철수"
```

## 4. 제어문 — "조건에 따라 다르게, 반복해서"

### if / elif / else
```python
if x > 0:
    print("양수")
elif x == 0:
    print("0")
else:
    print("음수")
```
파이썬은 중괄호 `{}` 대신 **들여쓰기(보통 스페이스 4칸)**로 코드 블록을 구분한다.
들여쓰기가 안 맞으면 에러가 난다 — 이게 다른 언어와 가장 다른 점.

### for — "정해진 범위/컬렉션을 순회"
```python
for i in range(5):        # range(5) = 0,1,2,3,4 다섯 개 숫자를 순서대로
    print(i)

for x in [10, 20, 30]:    # 리스트의 각 원소를 순서대로 x에 대입
    print(x)

for i, x in enumerate([10, 20, 30]):   # 인덱스와 값을 동시에: (0,10) (1,20) (2,30)
    print(i, x)
```
`range(시작, 끝, 간격)`처럼 인자를 더 줄 수도 있다. `range(2, 10, 2)` → 2,4,6,8
(끝값 10은 포함 안 됨 — **항상 끝값 미포함**인 게 실수 포인트).

### while — "조건이 참인 동안 반복"
```python
i = 0
while i < 5:
    print(i)
    i += 1     # 이걸 깜빡하면 무한루프
```

## 5. 리스트와 슬라이싱 — "여러 값을 담는 상자, 그 상자의 일부만 꺼내기"

```python
arr = [10, 20, 30, 40, 50]
arr[0]        # 10  (첫 번째, 인덱스는 0부터 시작)
arr[-1]       # 50  (마지막 원소)
arr[1:3]      # [20, 30]  (인덱스 1부터 3 "직전"까지 → 끝은 미포함)
arr[:2]       # [10, 20]  (처음부터 인덱스 2 전까지)
arr[2:]       # [30, 40, 50]  (인덱스 2부터 끝까지)
arr[::-1]     # [50, 40, 30, 20, 10]  (전체를 거꾸로. 세 번째 값이 "간격", -1은 역순)
arr.append(60)     # 맨 뒤에 추가
arr.pop()          # 맨 뒤 원소를 꺼내면서 삭제
len(arr)            # 리스트 길이
```
`arr[시작:끝:간격]` — 셋 다 생략 가능하고, 생략하면 각각 "처음부터", "끝까지",
"1칸씩"이 기본값이다. `[::-1]`이 자주 쓰이는 이유는 시작·끝을 다 생략하고 간격만
-1로 줘서 "전체를 거꾸로"가 되기 때문.

## 6. 자주 쓰는데 낯선 내장 함수들 — 하나씩 뜯어보기

이 함수들은 뒤에 나오는 모든 노트의 예시 코드에 반복해서 등장한다. 여기서 확실히
잡고 넘어갈 것.

### `len(x)` — 길이를 센다
```python
len([1,2,3])     # 3
len("hello")     # 5
```

### `range(n)` — 0부터 n-1까지 숫자를 하나씩 만들어내는 것
반복문에서만 주로 쓴다. `list(range(5))`로 실제 리스트로 눈에 보이게 확인해볼 수 있다
→ `[0, 1, 2, 3, 4]`.

### `sorted(x)` vs `x.sort()` — 정렬
```python
arr = [3, 1, 2]
sorted(arr)     # [1, 2, 3] 을 "새로" 만들어서 돌려줌. arr 자체는 안 바뀜
arr.sort()      # arr 자기 자신을 정렬해버림 (반환값 없음, None)
```
**차이가 헷갈리면**: `sorted()`는 함수라 "이걸 넣으면 정렬된 게 나온다"고 생각하고,
`.sort()`는 리스트가 가진 기능(메서드)이라 "그 리스트 자신을 바꾼다"고 생각하면 된다.

### `map(함수, 리스트)` — 리스트의 모든 원소에 같은 함수를 적용
```python
arr = ["1", "2", "3"]           # 문자열 리스트
result = list(map(int, arr))    # 각 원소에 int()를 적용 → [1, 2, 3]
```
`map`은 "리스트를 하나씩 순회하며 함수를 적용해서 새로운 걸 만든다"는 뜻이다.
`map(int, arr)` 자체는 결과를 바로 안 보여주고(제너레이터라는 특수한 상태), 눈으로
보려면 `list(...)`로 감싸야 한다. **입력 파싱에서 가장 많이 쓰는 패턴**:
```python
n, m = map(int, input().split())
# input().split()이 문자열 리스트를 만들고, map(int, ...)이 각각을 정수로 바꾼다
```

### `lambda` — 이름 없이 즉석에서 만드는 짧은 함수
```python
def square(x):        # 이렇게 이름 붙여 정의하는 대신
    return x * x

square2 = lambda x: x * x    # 이렇게 한 줄로: lambda 매개변수: 반환값
```
`lambda`는 `def`로 함수를 따로 만들기 귀찮을 만큼 짧을 때, 특히 **`sort()`나
`sorted()`의 `key=` 자리에 즉석으로 넘길 때** 쓴다.
```python
people = [("kim", 25), ("lee", 20)]
people.sort(key=lambda x: x[1])   # "각 원소 x에 대해 x[1](나이)을 기준으로 정렬해줘"
```
`key=`에 넘긴 함수(여기선 lambda)는 정렬 기준이 되는 값을 계산하는 역할만 한다.

### `enumerate(리스트)` — 인덱스와 값을 같이 뽑기
```python
for i, val in enumerate(["a", "b", "c"]):
    print(i, val)     # 0 a / 1 b / 2 c
```
"인덱스가 왜 필요한지"는 나중에 (원래 순서를 기억해야 하는 문제 등) 나온다. 지금은
`enumerate`가 "인덱스, 값 쌍을 만들어준다"는 것만 기억.

### `zip(리스트1, 리스트2)` — 여러 리스트를 같은 위치끼리 짝짓기
```python
names = ["kim", "lee"]
ages = [25, 20]
for name, age in zip(names, ages):
    print(name, age)   # kim 25 / lee 20
```

### `f-string` — 문자열 안에 변수 값 끼워넣기
```python
name = "철수"
score = 90
print(f"{name}의 점수는 {score}점")   # "철수의 점수는 90점"
```
문자열 앞에 `f`를 붙이고 `{}` 안에 변수를 쓰면 그 값이 그대로 들어간다. 문자열을
`+`로 이어붙이는 것보다 훨씬 읽기 쉽다.

## 3.5 리스트 컴프리헨션 — for문을 한 줄로

```python
squares = [x*x for x in range(5)]           # [0, 1, 4, 9, 16]
# 풀어쓰면:
squares = []
for x in range(5):
    squares.append(x*x)

evens = [x for x in range(10) if x % 2 == 0]   # 조건까지: [0,2,4,6,8]
```
"`[식 for 변수 in 반복대상 (조건)]`" 형태. 처음엔 어색해도 나중 노트의 예시 코드에
계속 나오므로 여기서 익혀둘 것.

## 4. 자주 하는 실수 (파이썬 문법 자체에서)
- 들여쓰기가 안 맞음 (스페이스와 탭을 섞어 씀) — 에디터 설정에서 탭을 스페이스로
  자동 변환하게 해둘 것
- `range(n)`이 0부터 n-1까지라는 걸 잊고 하나씩 오차가 남 (오프바이원)
- `sort()`의 반환값(`None`)을 변수에 저장하려다 실패 — `x = arr.sort()`는 `x`가 `None`
- `==`(비교)과 `=`(대입)을 헷갈림 — `if x = 5`는 에러, `if x == 5`가 맞음

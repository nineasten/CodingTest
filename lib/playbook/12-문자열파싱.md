## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 구분자로 단순 분리
`"2021,01,15"`처럼 쉼표로 이어진 날짜 문자열을 연/월/일로 나눠야 한다고 하자.
```python
s = "2021,01,15"
parts = s.split(',')   # ['2021', '01', '15']
year, month, day = parts
```

### 상황 B: 중첩 구조 해석 (괄호, 집합 표기 등)
`"{{20,111},{111}}"`처럼 중괄호로 감싼 집합이 중첩되어 있고, 이걸 안쪽 원소부터 순서
대로 해석해야 하는 문제("튜플"류)를 생각해보자. 문자열을 왼쪽부터 한 글자씩 훑으며
괄호 깊이를 직접 세면, 깊이 계산 하나만 틀려도 전체가 어긋난다. 정규식으로 "중첩되지
않은 가장 안쪽 `{}` 덩어리"를 통째로 뽑아내면 실수할 여지가 훨씬 줄어든다.
```python
import re
s = "{{20,111},{111}}"
tokens = re.findall(r'\{[^{}]*\}', s)   # 안쪽 {}만 매칭 (더 바깥 {}는 안 걸림)
print(tokens)   # ['{20,111}', '{111}']
```

### 상황 C: 문자열 뒤집기/부분 비교
`"level"`이 회문(앞뒤가 같은 문자열)인지 확인하거나, 긴 문자열에서 특정 구간만 잘라
비교해야 할 때 쓰는 기본 슬라이싱들이다.
```python
s = "level"
s[::-1]        # "level" — 뒤집어도 같으니 회문
s == s[::-1]   # True

t = "hello world"
t[6:11]        # "world" — 인덱스 6부터 11 "직전"까지
t[6:100]       # "world" — 끝 인덱스가 범위를 넘어가도 에러 안 나고 있는 만큼만 반환
```

### 상황 D: 문자 단위 변환 (암호화/치환)
시저 암호처럼 `"AB"`를 3칸씩 밀어 `"DE"`로 바꿔야 한다고 하자. 각 글자를 아스키 코드로
바꿔서 `k`만큼 더한 뒤 다시 26으로 나눈 나머지를 취하면 `'z'` 다음엔 다시 `'a'`로
돌아가는("wrap-around") 효과가 자동으로 생긴다.
```python
def shift(s, k):
    result = []
    for c in s:
        if c.isalpha():
            base = ord('A') if c.isupper() else ord('a')
            result.append(chr((ord(c) - base + k) % 26 + base))
        else:
            result.append(c)   # 알파벳이 아니면 그대로 둠
    return ''.join(result)

shift("AB", 3)   # "DE"
shift("XYZ", 3)  # "ABC" — Z에서 3칸 밀면 26을 넘겨서 다시 A로 돌아옴
```

### 상황 E: 접두사/접미사, 포함 여부 검사
파일명 `"report_2024.pdf"`가 `.pdf`로 끝나는지, 로그 문자열에 `"ERROR"`가 포함돼
있는지 확인할 때 쓴다.
```python
"report_2024.pdf".endswith(".pdf")   # True
"report_2024.pdf".startswith("report")  # True
"ERROR" in "2024-01-01 ERROR: timeout"  # True
```

## 3. 자주 하는 실수
- 대소문자를 안 가리는 문제인데 그대로 비교 — `.lower()`/`.upper()`로 통일
- 슬라이싱이 범위를 넘어가도 조용히 잘리는 것을 이용 안 하고 별도 예외처리를 함 (몰라서
  코드가 길어짐) — `s[i:i+5]`는 i+5가 넘어가도 에러 없이 있는 만큼만 반환
- `str`은 불변(immutable) — 반복 안에서 `+=`로 문자열을 계속 이어붙이면 O(N²). 리스트에
  모았다가 `''.join()`으로 한 번에 합칠 것

## 4. Python 잡기술
- `''.join(list_of_str)` — 문자열 이어붙이기는 항상 이 방식
- `str.isalpha()`, `.isdigit()`, `.isupper()` — 문자 종류 판별
- `Counter(s)` — 문자열 내 문자 빈도수

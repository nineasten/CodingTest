# 문자열 파싱

## 1. 언제 이 기술인가 — 문제 속 신호
"문자열이 다음 형식으로 주어진다", "괄호/쉼표로 구분된 중첩 구조", "특정 패턴을 찾아라"

## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 구분자로 단순 분리
```python
parts = s.split(',')
```

### 상황 B: 중첩 구조 해석 (괄호, 집합 표기 등)
정규식으로 토큰을 통째로 뽑아낸 뒤 하나씩 처리하는 게 직접 문자 단위로 파싱하는 것보다
실수가 적다.
```python
import re
tokens = re.findall(r'\{[^{}]*\}', s)   # 중첩 안 된 가장 안쪽 {} 부터
```

### 상황 C: 문자열 뒤집기/부분 비교
```python
s[::-1]                      # 뒤집기
s[i:j]                       # 부분 문자열, 슬라이싱은 범위를 벗어나도 에러 안 남(주의)
```

### 상황 D: 문자 단위 변환 (암호화/치환)
```python
result = ''.join(chr((ord(c) - ord('a') + k) % 26 + ord('a')) if c.isalpha() else c for c in s)
```

### 상황 E: 접두사/접미사, 포함 여부 검사
```python
s.startswith('ab'); s.endswith('cd'); 'ab' in s
```

## 3. 자주 하는 실수
- 대소문자를 안 가리는 문제인데 그대로 비교 — `.lower()`/`.upper()`로 통일
- 슬라이싱이 범위를 넘어가도 조용히 잘리는 것을 이용 안 하고 별도 예외처리를 함 (몰라서
  코드가 길어짐) — `s[i:i+5]`는 i+5가 넘어가도 에러 없이 있는 만큼만 반환
- `str`은 불변(immutable) — 반복 안에서 `+=`로 문자열을 계속 이어붙이면 O(N²). 리스트에
  모았다가 `''.join()`으로 한 번에 합칠 것

## 4. Python 잡기술
- `''.join(list_of_str)` — 문자열 이어붙이기는 항상 이 방식
- `str.isalpha()`, `.isdigit()`, `.isupper()` — 문자 종류 판별
- `Counter(s)` — 문자열 내 문자 빈도수

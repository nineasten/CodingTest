# 2D 격자 ★ 시험 최다 출제

## 1. 언제 이 기술인가 — 문제 속 신호
"N×M 지도", "격자", "상하좌우로 이동", "인접한 칸", "회전시킨다", "특정 범위의 칸을
갱신" 이 나오면 이것. 구현·시뮬레이션과 종종 겹친다(격자 위에서 규칙을 시뮬레이션).

## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 상하좌우 네 방향으로 이동하며 범위를 벗어나지 않게 하기
격자 문제의 90%는 여기서 시작한다. 예를 들어 3×3 격자에서 `(1,1)`(가운데 칸)에 있는
로봇이 상하좌우로 한 칸씩 움직일 수 있는 칸을 모두 찾는다고 하자. 방향을 `dr`/`dc`
배열로 미리 빼두면 "방향이 4개냐 8개냐"에 코드가 영향을 안 받는다.
```python
dr = [-1, 1, 0, 0]   # 상, 하, (좌우는 아래 dc에서)
dc = [0, 0, -1, 1]   # (상하는 위 dr에서), 좌, 우
r, c = 1, 1
for k in range(4):
    nr, nc = r + dr[k], c + dc[k]
    if 0 <= nr < 3 and 0 <= nc < 3:   # 범위 체크는 항상 이렇게 한 줄로 분리
        print(nr, nc)   # (0,1) (2,1) (1,0) (1,2) — 네 방향 모두 격자 안이라 다 출력됨
```
`(0,0)`(모서리)에서 같은 코드를 돌리면 `dr[0]`으로 만든 `(-1,0)`은 범위 밖이라 그
방향만 자동으로 걸러진다 — 매 방향마다 따로 `if`를 쓸 필요가 없다. 8방향(대각선 포함)은
`dr = [-1,-1,-1,0,0,1,1,1]`, `dc = [-1,0,1,-1,1,-1,0,1]`.

### 상황 B: 격자를 시계방향/반시계방향 90도 회전
`grid = [[1,2],[3,4]]`(2×2)를 시계방향으로 90도 돌리면 `[[3,1],[4,2]]`가 되어야 한다.
반복문으로 `new[c][N-1-r] = grid[r][c]` 식으로 직접 인덱스를 계산하면 부호 하나만
틀려도 결과가 다 어긋난다. `zip`을 쓰면 "행을 뒤집고 나서 열끼리 묶는다"는 동작
한 번으로 회전이 끝난다.
```python
grid = [[1, 2], [3, 4]]
rotated_cw = list(zip(*grid[::-1]))    # grid[::-1] = [[3,4],[1,2]] → zip으로 열 묶기
print(rotated_cw)   # [(3, 1), (4, 2)] — 시계방향 90도 회전 결과
rotated_ccw = list(zip(*grid))[::-1]   # 반시계방향 90도
```
결과가 튜플들의 리스트라 리스트가 필요하면 `list(map(list, rotated_cw))`로 한 번 더
감싼다.

### 상황 C: 특정 조건의 칸을 "동시에" 갱신 (생명게임류 함정)
"이번 턴에 이웃이 2개 이상인 칸을 전부 벽으로 바꾼다"처럼 **격자 전체를 같은 기준으로
한꺼번에** 갱신해야 하는 문제를 생각해보자. 격자를 순회하면서 조건에 맞는 칸을 바로
바꿔버리면, 뒤에서 순회할 때 **방금 내가 바꾼 값**을 이웃으로 참조하게 되어 결과가
꼬인다. 그래서 "바꿀 좌표만 먼저 모아두고, 순회가 다 끝난 뒤에 한꺼번에" 적용한다.
```python
to_update = []
for r in range(N):
    for c in range(M):
        if condition(grid, r, c):   # 이 시점엔 아직 grid가 원본 그대로
            to_update.append((r, c))
for r, c in to_update:               # 순회가 끝난 뒤 한꺼번에 반영
    grid[r][c] = new_value
```

### 상황 D: 격자 위에서 BFS/DFS (연결된 영역 찾기, 최단거리)
5×5 지도에서 `(0,0)`부터 시작해 "벽(`'X'`)이 아닌 칸만 지나서 목표 칸까지 최소 몇 칸을
움직여야 하는가"를 구하는 문제라면, 격자를 그래프처럼 보고 BFS를 돌린다. 방향 이동과
범위 체크는 상황 A와 똑같고, 여기에 "이미 방문한 칸인가"와 "이동 가능한 칸인가" 두
조건만 추가된다. 자세한 BFS 원리는 16번 노트 참고.
```python
from collections import deque
visited = [[False]*M for _ in range(N)]
q = deque([(0, 0)])
visited[0][0] = True
while q:
    r, c = q.popleft()
    for k in range(4):
        nr, nc = r+dr[k], c+dc[k]
        if 0 <= nr < N and 0 <= nc < M and not visited[nr][nc] and grid[nr][nc] != 'X':
            visited[nr][nc] = True
            q.append((nr, nc))
```

### 상황 E: 2D 배열 초기화 함정
`N=3`인 3×3 격자를 0으로 채워 만들려고 `[[0]*3]*3`이라고 쓰면, 겉보기엔 `[[0,0,0],
[0,0,0],[0,0,0]]`처럼 보이지만 **세 행이 전부 같은 리스트 객체를 가리킨다.** 그래서
`grid[0][0] = 9`를 한 번만 해도 세 행 모두 첫 칸이 9로 바뀌는(`[[9,0,0],[9,0,0],
[9,0,0]]`) 이상한 결과가 나온다.
```python
grid = [[0]*3 for _ in range(3)]   # 올바름 — 매번 새 리스트를 만들어 행마다 독립
# grid = [[0]*3]*3                 # 틀림 — 한 칸만 바꿔도 모든 행이 같이 바뀜
grid[0][0] = 9
print(grid)   # [[9,0,0], [0,0,0], [0,0,0]] — 첫 행만 정확히 바뀜 (컴프리헨션 버전)
```

## 3. 자주 하는 실수
- 행(row)/열(col)을 x/y로 헷갈려 뒤집힘 — 변수명을 **r, c로 통일**하고 "r은 세로,
  c는 가로"라고 못박아 놓는다
- 범위 체크를 이동 후가 아니라 이동 전 좌표에만 함 — 이동한 좌표(`nr, nc`)를 체크할 것
- `[[0]*M]*N` 얕은 복사 함정 (상황 E)
- 회전/반전을 여러 번 적용할 때 좌표계가 누적으로 꼬임 — 한 번에 하나씩 검증

## 4. Python 잡기술
- 회전: `list(zip(*grid[::-1]))` (상황 B)
- 전치(transpose): `list(zip(*grid))`
- 범위체크: `0 <= nr < N and 0 <= nc < M`
- 격자를 문자열 리스트로 받았으면 `grid[r][c]`로 바로 접근 가능 (문자열은 인덱싱 가능)

### 좌표 2배 확장 — 연속 좌표를 격자로 옮길 때 (실전에서 데임)
좌표평면 위의 **도형(선)**을 정수 격자의 **칸**으로 옮기는 문제에서, 서로 다른 두
선의 간격이 1이면 격자에서는 **바로 옆칸이 되어 붙어버린다.** 그러면 BFS가 실제로는
건널 수 없는 폭 1짜리 틈을 한 칸에 뛰어넘어, 존재하지 않는 지름길을 만든다.

예를 들어 `[[3,1,4,7]]`처럼 **폭이 1인 직사각형**은 "내부"가 아예 없어서
(`range(3+1, 4)`가 빈 범위) 막대 전체가 통행 가능으로 남고, `(3,3)`에서 `(4,3)`으로
1칸에 관통해 버린다. 실제로는 막대를 돌아가야 하므로 답이 5인데 1이 나온다.

```python
# 입력을 받자마자 전부 2배로
x1, y1, x2, y2 = x1*2, y1*2, x2*2, y2*2
sx, sy, ex, ey = sx*2, sy*2, ex*2, ey*2
grid = [[0]*101 for _ in range(101)]   # 좌표 최대 50 → 2배 100, 여유 +1
...
return dist // 2                        # 거리도 2배로 세어졌으므로 되돌림
```
**왜 하필 2배인가**: 좌표가 서로 다른 정수면 두 선 사이 최소 간격은 정확히 1이다.
1은 "사이에 정수 칸이 하나도 못 들어가는" 유일한 간격이라, 2배만 하면 간격이 2가
되어 **반드시 빈 칸(=벽)이 하나 끼어든다.** 3배·4배는 필요 없다.

### 도형이 여러 개 겹칠 때 테두리만 남기기
"전부 채우기"와 "내부 지우기"를 **각각 별개의 루프로 분리**해야 한다.
도형마다 채우고-지우고를 번갈아 하면, 뒤 도형의 "내부 지우기"가 앞 도형의 테두리를
아직 안 그린 상태에서 돌거나 덮어써서 결과가 어긋난다.
```python
for x1, y1, x2, y2 in rects:            # 1패스: 영역 전체를 길로
    for x in range(x1, x2+1):
        for y in range(y1, y2+1):
            grid[x][y] = 1
for x1, y1, x2, y2 in rects:            # 2패스: 순수 내부만 벽으로
    for x in range(x1+1, x2):
        for y in range(y1+1, y2):
            grid[x][y] = 0
```

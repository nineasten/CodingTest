# 2D 격자 ★ 시험 최다 출제

## 1. 언제 이 기술인가 — 문제 속 신호
"N×M 지도", "격자", "상하좌우로 이동", "인접한 칸", "회전시킨다", "특정 범위의 칸을
갱신" 이 나오면 이것. 구현·시뮬레이션과 종종 겹친다(격자 위에서 규칙을 시뮬레이션).

## 2. 상황별 한국어 설명 + 예시 코드

### 상황 A: 상하좌우 네 방향으로 이동하며 범위를 벗어나지 않게 하기
격자 문제의 90%는 여기서 시작한다. **방향을 dx/dy 배열로 빼두면** 방향이 4개든 8개든
코드가 안 바뀐다. 범위 체크는 반드시 한 줄로 분리해 실수를 줄인다.
```python
dr = [-1, 1, 0, 0]   # 상, 하
dc = [0, 0, -1, 1]   # 좌, 우
for k in range(4):
    nr, nc = r + dr[k], c + dc[k]
    if 0 <= nr < N and 0 <= nc < M:   # 범위 체크는 항상 이렇게 한 줄로
        ...
```
8방향(대각선 포함)은 `dr = [-1,-1,-1,0,0,1,1,1]`, `dc = [-1,0,1,-1,1,-1,0,1]`.

### 상황 B: 격자를 시계방향/반시계방향 90도 회전
행렬 회전은 반복문으로 직접 짜면 인덱스 실수가 잦다. `zip`으로 한 줄에 처리하는 게
훨씬 안전하다.
```python
rotated_cw = list(zip(*grid[::-1]))    # 시계방향 90도
rotated_ccw = list(zip(*grid))[::-1]   # 반시계방향 90도 (결과가 튜플이면 list(map(list, ...)))
```

### 상황 C: 특정 조건의 칸을 "동시에" 갱신 (생명게임류 함정)
"이번 턴에 조건을 만족하는 칸을 전부 바꾼다" — **원본을 보면서 원본을 바로 수정하면
안 된다.** 먼저 바꿀 좌표를 리스트에 모으고, 순회가 끝난 뒤 한꺼번에 적용한다.
```python
to_update = []
for r in range(N):
    for c in range(M):
        if condition(grid, r, c):
            to_update.append((r, c))
for r, c in to_update:
    grid[r][c] = new_value
```

### 상황 D: 격자 위에서 BFS/DFS (연결된 영역 찾기, 최단거리)
`visited`를 별도 2D 배열로 두거나, 방문한 칸을 특수 값으로 마킹한다. 큐/스택은
01번(자료형), BFS·DFS는 16번 노트 참고. 여기서는 격자 특유의 경계 체크만 강조.
```python
from collections import deque
visited = [[False]*M for _ in range(N)]
q = deque([(0, 0)])
visited[0][0] = True
while q:
    r, c = q.popleft()
    for k in range(4):
        nr, nc = r+dr[k], c+dc[k]
        if 0 <= nr < N and 0 <= nc < M and not visited[nr][nc] and grid[nr][nc] == target:
            visited[nr][nc] = True
            q.append((nr, nc))
```

### 상황 E: 2D 배열 초기화 함정
`[[0]*M]*N`은 **같은 리스트를 N번 참조**해서 한 칸만 바꿔도 모든 행이 바뀐다. 반드시
컴프리헨션으로 만들 것.
```python
grid = [[0]*M for _ in range(N)]   # 올바름
# grid = [[0]*M]*N                # 틀림 — 모든 행이 같은 객체를 가리킴
```

## 3. 자주 하는 실수
- 행(row)/열(col)을 x/y로 헷갈려 뒤집힘 — 변수명을 **r, c로 통일**하고 "r은 세로,
  c는 가로"라고 못박아 놓는다
- 범위 체크를 이동 후가 아니라 이동 전 좌표에만 함 — 이동한 좌표(`nr, nc`)를 체크할 것
- `[[0]*M]*N` 얕은 복사 함정 (상황 E)
- 회전/반전을 여러 번 적용할 때 좌표계가 누적으로 꼬임 — 한 번에 하나씩 검증

## 4. Python 잡기술
- 회전: `list(zip(*grid[::-1]))` (상황 B)
- 전치(transpose): `list(zip(*grid))`
- 범위체크: `0 <= nr < N and 0 <= nc < M`
- 격자를 문자열 리스트로 받았으면 `grid[r][c]`로 바로 접근 가능 (문자열은 인덱싱 가능)

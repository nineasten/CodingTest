실제 소프티어 1차 코딩테스트 형식(5문항 · 2시간)으로 모의고사를 낸다.

## 출제

1. `curriculum/problem-bank.md`에서 **쉬움 2 · 중간 2 · 어려움 1** 구성으로 5문제를
   고른다 (이미 완료 처리된 문제는 되도록 피한다). 부족하면 새 문제를 WebFetch로
   검증 후 은행에 추가해 채운다.
2. 5문제를 한 번에 제시한다 — 출처·ID·URL·난이도를 각각 명시. 이번엔 처음 만나는
   유형이어도 플레이북 요약을 먼저 주지 않는다(실전 감각 훈련이므로).
3. **진행 중 힌트를 주지 않는다.** 사용자가 `/hint`를 호출해도 "모의고사 중에는 힌트를
   지원하지 않습니다. 실제 시험 감각을 유지하세요"라고 안내한다.
4. `problems/mock-<날짜>/` 아래 5개 문제 폴더를 만든다 (형식은 `/next`와 동일하되
   힌트 게이지 없이 시작 시각만 기록).

## 종료 후 리뷰

사용자가 "끝났어" 또는 결과를 보고하면:
1. 각 문제를 코드 실행 없이 리뷰 (정답성/복잡도/엣지).
2. **"문제 선택이 옳았는가"를 반드시 포함한다.** 시간을 많이 쓴 문제가 정말 풀 만한
   문제였는지, 더 쉬운 문제를 나중에 배치해 시간을 낭비하지 않았는지 짚는다. 2~3솔이
   커트인 시험이므로 이 판단 훈련이 핵심이다.
3. `PROGRESS.md`의 "이번 주 모의고사" 표에 회차·날짜·결과 요약을 추가한다.
4. 틀리거나 못 푼 문제는 각각 `/retro`를 이어서 하도록 제안한다.

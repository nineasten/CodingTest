---
description: 사용자가 직접 찾은 프로그래머스 URL로 문제 등록 (/next의 수동 버전)
---

사용자가 `/prob $ARGUMENTS` (프로그래머스 URL)를 호출했다.

1. WebFetch로 URL을 열어 제목·난이도·카테고리를 확인한다. 프로그래머스는 로그인이
   필요해 본문을 못 가져올 수 있다 — 실패하면 **사용자에게 문제 본문(제목, 설명,
   제약, 입출력 예시)을 직접 붙여넣어 달라고 요청**한다. 임의로 지어내지 않는다.
2. 확인된 정보로 `/next`와 동일한 절차를 밟는다: 유형·난이도를 판단해 커버리지 보드의
   어느 칸에 해당하는지 정하고, 제약을 보고 목표 복잡도·목표 시간을 계산하고,
   `problems/<번호>-<문제명>/` 폴더와 `problem.md`, 헤더 있는 `sol.py`를 생성한다.
3. 이 문제가 `curriculum/problem-bank.md`에 없으면 새 행으로 추가한다(URL 검증
   완료 상태이므로 바로 등록 가능).
4. 처음 만나는 유형이면 `/next`처럼 플레이북 요약을 먼저 보여준다.

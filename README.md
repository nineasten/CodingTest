# 소프티어 코딩테스트 대비 워크스페이스

Claude Code를 코딩테스트 개인 과외 선생으로 쓰기 위한 워크스페이스. 배경과 근거는
`curriculum/exam-analysis.md`, 운영 규칙은 `CLAUDE.md` 참고.

## 슬래시 명령어란?

채팅창에 `/`로 시작하는 짧은 단어를 치면, 미리 저장해둔 긴 지시문이 대신 실행되는
단축키다. "이 코드 리뷰해줘, 정답성 보고 복잡도 보고 엣지 보고 파이썬답게 리팩토링하고
오답노트에 기록해줘"를 매번 칠 필요 없이 `/review` 한 단어면 된다.

**쓰는 법**: 입력창에 `/`를 치면 목록이 자동완성으로 뜬다. 골라서 엔터. 뒤에 말을
덧붙여도 된다 (`/next 그래프`, `/review 30번 케이스 틀렸어`).

**동작 원리**: `.claude/commands/review.md` 파일이 있으면 `/review`가 생긴다.
파일 이름 = 명령어 이름, 파일 내용 = 실행될 지시문. 열어서 문구를 고치면 동작이 바뀐다.

## 9개 명령어

| 명령어 | 언제 | 하는 일 |
|---|---|---|
| **`/next`** | **매 문제 시작. 가장 많이 쓸 명령** | 프로그래머스 문제를 골라서 제시 — 출처·ID·링크·제약·목표 복잡도·목표 시간까지. 바로 코딩만 하면 됨. 폴더·`sol.py` 헤더도 같이 생성 |
| **`/learn <유형>`** | 문제 풀기 전 기술 학습 | 해당 유형 플레이북(한국어 설명 + 예시 코드)을 훑음. 새 유형은 `/next`가 자동으로 요약해줌 |
| `/hint` | 15분 막혔을 때 | 힌트 한 단계만 더 공개 + `sol.py` 헤더의 힌트 게이지 갱신 |
| `/review` | 코드 완성/제출 후 | 반례·복잡도·엣지 점검 + Fancy 리팩토링, 기록 갱신 |
| `/retro` | 문제 끝냈을 때 | 자동으로 원인 태깅 + 전 기록 파일 갱신 + 커버리지 보드 갱신 + 복습 예약 + 커밋·푸시 |
| `/due` | 하루 시작할 때 | 오늘 재풀이할 문제 목록 |
| `/drill <유형>` | 약점 몰아 훈련 | 코드 안 짜고 "어떻게 풀지 아이디어만" 빠르게 답하는 속성 훈련 |
| `/mock` | 주 2회 | 5문항 2시간 실전 세트 + 문제 선택 전략 리뷰 |
| `/prob <URL>` | 내가 찾은 문제를 쓸 때 | 그 URL로 문제 등록 (`/next`의 수동 버전) |

## 하루 흐름

```
/due          → 오늘 복습 문제 먼저 재풀이
/next         → 오늘의 새 문제 받기 (유형·제약·목표 복잡도·목표 시간까지 같이 나옴)
   (바로 15분 자력 코딩)
/hint         → 막히면. 그래도 막히면 한 번 더
   (프로그래머스에 직접 제출)
/review       → 결과 알려주고 리뷰 + 잡기술 습득
/retro        → 자동 기록 + 복습 예약 + 커밋
/next         → 다음 문제 (하루 필수 2문제, 상한 없음)
```

## 힌트 4단계

1. **관찰** — "N이 10^5인데 지금 접근은 몇 번 도나요?" (질문만)
2. **접근** — 유형만 알려줌
3. **핵심 로직** — 점화식/불변식/자료구조를 말로 (코드 없음)
4. **코드** — 전체 풀이 + 줄별 해설

`/hint`를 부를 때마다 한 단계씩만 열린다. 4단계를 바로 원하면 "4단계"라고 명시해야 함.

## 파일 구조

```
CodingTest/
├─ README.md / CLAUDE.md          # 이 파일들
├─ INSIGHTS.md                    # 유형별 공략 인사이트 — 시험 직전 최종 병기
├─ PROGRESS.md                    # 커버리지 보드 + 목표일 + 문제 로그
├─ curriculum/
│  ├─ exam-analysis.md            # 시험 분석 (근거 자료)
│  └─ problem-bank.md             # URL 검증된 프로그래머스 문제 은행
├─ problems/<번호>-<문제명>/
│  ├─ problem.md                  # 출처·ID·URL, 요약, 제약, 목표 복잡도
│  ├─ sol.py                      # 헤더에 출처 + 힌트 게이지
│  └─ notes.md                    # 리뷰·회고 기록
├─ lib/
│  ├─ playbook/                   # 파이썬 기초 문법 1개 + 유형별 선행 학습 노트 16개
│  └─ cheatsheet.md                # Python 잡기술 한 줄 요약
└─ review/
   ├─ queue.md                    # 간격 반복 큐
   └─ mistakes.md                 # 실수 태그 누적
```

## 매일 21시 진행도 알림

`/retro`가 자동으로 커밋·푸시하고, 매일 21시 클라우드 루틴이 저장소를 읽어 그날 새
문제 수를 센다. 2개 미만이면 핸드폰 알림, 채웠으면 알림 없음. 일요일엔 주간 요약.
설정 상태는 `PROGRESS.md` 상단 참고.
